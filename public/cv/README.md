# CV téléchargeables

Les deux CV PDF utilisés par les boutons de téléchargement du portfolio sont :

- `CV_Wissem_Attouf FR.pdf` — version française
- `CV_Wissem_Attouf_EN.pdf` — version anglaise

Les liens de téléchargement sont centralisés dans `lib/cv.ts`. Les fichiers HTML `Wissem-Attouf-CV-FR.html` et `Wissem-Attouf-CV-EN.html` sont des versions de secours imprimables au format A4 si les PDF ne sont pas disponibles dans l’environnement de déploiement.

Maintenir les dates, les intitulés de poste, la formation et la description de Neivos Facture cohérents entre les CV, le portfolio, GitHub et LinkedIn.
